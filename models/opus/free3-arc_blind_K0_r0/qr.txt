# Qualitative reasoning table (arch.py: "qualitative reasoning").
#
# Q name: words          a quantity named by these words; it has a direction only when a direction word
#                        (see + / -) stands next to it ("the temperature increases", "more friction")
# E name: words          an event or thing whose mention alone counts as an increase ("pollution",
#                        "a drought", "adding salt"); a nearby direction word can still reverse it
# I name +|-: words      words that carry their own direction ("hotter" = temperature up); a nearby
#                        direction word multiplies it ("less hotter" is rare, "reduce heating" = down)
# + : words              generic direction words: up (they apply to the words on both sides)
# - : words              generic direction words: down
# +> : words / -> : words  the same, but they apply only to the words after them ('more water', 'without light')
# r+ : words / r- : words  rate words ('faster', 'slowly'): they set the direction of a process, not of a word
#                        with its own direction ('cooled slowly' is a slow cooling, not a warming)
# R a b ... > x y ...    every listed cause increases every listed effect
# R a b ... < x y ...    every listed cause decreases every listed effect
# Words are matched by their Porter stem, so 'evaporation' also covers 'evaporates', 'evaporating'.

+ : increase increases increased increasing raise raises raised raising rise rises rising rose strengthen add adds added adding gain gains gained grow grows growing grew boost boosts improve improves improved improving double doubles doubled triple planting planted
+> : more greater higher larger largest bigger biggest stronger strongest taller greatest maximum extra many lot lots high large big strong plenty abundant
- : decrease decreases decreased decreasing lowers lowered lowering reduce reduces reduced reducing weaken weakens drop drops dropped dropping fall falls fell falling shrink shrinks shrank shrinking lose loses losing lost loss remove removes removed removing removal cut cuts cutting limit limits limited prevent prevents prevented preventing stop stops stopped stopping blocked blocking lacks decline declines declining eliminate eliminates eliminated destroy destroys destroyed destruction halve die dies died dying death kill kills killed killing
-> : less fewer lower smaller smallest weaker weakest least minimum fewest lack lacking without little low small weak shortage scarce scarcity instead
r+ : faster fastest quickly quicker rapidly rapid sooner accelerate accelerates speeds
r- : slower slowest slowly gradually slows slow
